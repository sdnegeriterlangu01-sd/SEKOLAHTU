Aktifkan Sinkronisasi Cloud Google Sheets & Drive

Jika dimatikan, sistem akan beroperasi dalam Mode Simulasi Lokal (LocalStorage Browser).

Panduan Cepat Setup Backend:
  1. Buka file backend/Code.gs di repo ini dan salin kodenya.
  2. Buka spreadsheet baru di Google Sheets → Ekstensi → Apps Script.
  3. Jalankan fungsi setupDatabaseAndFolders untuk membuat tab & folder Drive otomatis.
  4. Klik Deploy → New Deployment → Web App (Execute as: Me, Access: Anyone).
  5. Salin URL Web App yang dihasilkan ke kotak di atas!
