Pengaturan Sistem & Backend Google Apps Script

Konfigurasi identitas kop surat sekolah dasar dan integrasi REST API Google Sheets & Drive gratis.

Mode Operasi

Online

Pilih apakah sistem beroperasi online terhubung ke Cloud atau offline lokal di peramban.

Mode Cloud (On / Disarankan):

Sinkronisasi multi-perangkat real-time ke Google Sheets, pengarsipan berkas ke Google Drive, dan otentikasi zero-trust via Supabase Auth.

Mode Lokal (Off / Demo Offline):

Bekerja tanpa koneksi server cloud. Seluruh data disimpan mandiri di memori browser (LocalStorage) cocok untuk demonstrasi dan uji coba cepat.

Konfigurasi Supabase (Otentikasi & Database Cloud)

Kredensial publik Supabase Auth untuk verifikasi sesi staf TU, Kepala Sekolah, dan Guru.

Zero Trust Auth

URL Project REST & Auth Supabase Anda.

Anon key bersifat publik & aman karena dilindungi oleh Row Level Security (RLS).

Token login selalu diverifikasi ulang di sisi server Google Apps Script.

Integrasi Google Apps Script (GAS) Web App Endpoint

Jembatan REST API gratis untuk membaca & menulis basis data Google Sheets dan Google Drive.

Zero Cost Serverless

Dapatkan URL ini setelah menerapkan (Deploy) script backend sebagai Web App.

Panduan Cepat Setup Backend Google Apps Script: Buka Panduan Lengkap →
  1. Buka file backend/Code.gs di repositori ini dan salin seluruh kodenya.
  2. Buka spreadsheet baru di Google Sheets → menu Ekstensi → Apps Script.
  3. Jalankan fungsi setupDatabaseAndFolders untuk menginisialisasi tabel & folder Drive secara otomatis.
  4. Klik Deploy → New Deployment → Web App (Execute as: Me, Access: Anyone).
  5. Salin URL Web App yang dihasilkan ke kotak input di atas lalu klik Uji Koneksi GAS.
